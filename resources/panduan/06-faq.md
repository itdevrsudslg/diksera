# Pertanyaan Umum (FAQ)

**Saya tidak bisa login, muncul "menunggu persetujuan".**
Akun Anda belum disetujui admin. Hubungi admin komite.

**Muncul "Terlalu banyak percobaan" saat login.**
Tunggu 1 menit lalu coba lagi. Gunakan *Lupa Password* bila lupa.

**Menu Validasi Logbook / badge KARU tidak muncul padahal saya kepala ruangan.**
Periksa *Jabatan Struktural* di Profil → Identitas, dan pastikan riwayat pekerjaan terbaru berisi unit yang Anda pimpin.

**Saat menambah logbook muncul "Unit Kerja Kosong".**
Isi menu Profil → Pekerjaan. Unit kerja terbaru menentukan kepala ruangan yang memvalidasi.

**Tombol Tambah Logbook tidak ada.**
Periode bulan tersebut sudah ditutup (lewat H+5). Hubungi admin bila perlu dibuka.

**Nama pasien tidak muncul otomatis.**
Data pasien diambil dari SIMRS. Bila tidak ditemukan atau koneksi belum tersedia, ketik nama secara manual.

**Tindakan yang saya cari tidak ada.**
Minta admin menambahkan/mengaktifkan tindakan di Master Tindakan.

**Ujian tidak bisa dibuka lagi setelah 3 kali gagal.**
Sesuai aturan, maksimal 3 kali percobaan. Hubungi admin untuk reset hasil ujian.

**Dokumen cetak menampilkan nama pejabat lama.**
Dokumen memakai pejabat yang berlaku pada tanggal terbit dokumen. Admin bisa memeriksa tanggal *Berlaku mulai* di menu Penanda Tangan.

**Tidak menerima notifikasi Telegram.**
Hubungkan ulang akun di menu Notifikasi Telegram dan pastikan bot tidak diblokir.
